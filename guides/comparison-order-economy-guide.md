# بخش اول — منطق

## ۱. نخ مشترک

چهار حوزه‌ی این جزوه در نگاه اول بی‌ربط‌اند. ربطشان این است:

```
مقایسه       →  چطور دو چیز را کنار هم بگذاری
ترتیب        →  چه چیزی کجا بنشیند
فاعل صوری    →  وقتی جایگاه فاعل خالی است، چه بگذاری
جانشینی      →  چطور چیزی را دوباره نگویی
واژه‌سازی     →  چطور یک کلمه را به جایگاه موردنیاز درآوری
```

هر پنج‌تا درباره‌ی **جایگاه** هستند: پر کردنش، مرتب کردنش، یا خالی گذاشتنش.

و همه‌شان یک ویژگی مشترک دارند که در فارسی نیست: **در انگلیسی جایگاه، معنا حمل می‌کند.** این محور بخش بعد است.

---

## ۲. پُلی از فارسی

اینجا یکی از عمیق‌ترین تفاوت‌های دو زبان است.

**فارسی ترتیب نسبتاً آزادی دارد**، چون نقش کلمات را با نشانه‌ها مشخص می‌کند — مخصوصاً «را»:

```
من کتاب را خریدم.
کتاب را من خریدم.
کتاب را خریدم من.
خریدم من کتاب را.
```

هر چهارتا قابل فهم‌اند. تأکیدشان فرق می‌کند ولی معنایشان یکی است، چون **«را» به تو می‌گوید کتاب مفعول است**، هرجا که باشد.

**انگلیسی چنین نشانه‌ای ندارد.** اسم‌ها در انگلیسی هیچ علامتی برای فاعل یا مفعول بودن نمی‌گیرند. تنها راه تشخیص، **جای کلمه** است:

```
The dog bit the man.        سگ مرد را گاز گرفت
The man bit the dog.        مرد سگ را گاز گرفت
```

همان کلمات، ترتیب متفاوت، **معنای وارونه**.

### نتیجه‌ی عملی

انگلیسی برای جبران این ضعف، **قواعد ترتیب سفت‌وسختی** ساخته است. جاهایی که در فارسی می‌توانی آزادانه جابه‌جا کنی، در انگلیسی نمی‌توانی:

```
❌ I like very much this film.       ✅ I like this film very much.
❌ He speaks fluently English.       ✅ He speaks English fluently.
❌ I go always to the gym.           ✅ I always go to the gym.
```

هر سه‌تا در فارسی معادل کاملاً روانی دارند:
```
من خیلی این فیلم را دوست دارم.       ✅ فارسی درست
او روان انگلیسی حرف می‌زند.          ✅ فارسی درست
من همیشه به باشگاه می‌روم.           ✅ فارسی درست
```

و همین دلیل خطاست: **ذهنت عادت دارد قید را هرجا که تأکید می‌خواهد بگذارد.** انگلیسی این آزادی را نمی‌دهد.

### یک استثنای مهم

ضمایر در انگلیسی **هنوز** نشانه‌ی نقش دارند — بازمانده‌ای از حالت‌های قدیمی:

```
I / me      he / him      she / her      we / us      they / them
```

برای همین `I saw him` درست است و `I saw he` غلط. این تنها جایی است که انگلیسی به تو نشانه می‌دهد، و اتفاقاً همان‌جا فارسی‌زبان‌ها کمتر خطا می‌کنند.

# بخش دوم — مقایسه

## ۳. یک قالب، سه درجه

کل سیستم مقایسه سه قالب دارد:

```
برابری:   as + صفت + as
          Tehran is as crowded as Cairo.

برتری:    صفت‌تر + than
          Tehran is more crowded than Isfahan.

عالی:     the + صفتِ عالی
          Tehran is the most crowded city in Iran.
```

منفی برابری دو شکل دارد:
```
not as … as        Isfahan is not as crowded as Tehran.
less … than        Isfahan is less crowded than Tehran.    ← رسمی‌تر
```

⚠️ **`than` را جا نینداز.** خطای رایج:
```
❌ Tehran is more crowded from Isfahan.
❌ Tehran is more crowded that Isfahan.
✅ Tehran is more crowded than Isfahan.
```

فارسی «از» دارد («شلوغ‌تر **از**») و ذهن ممکن است `from` بیاورد.

## ۴. `-er` یا `more`

قاعده بر اساس **تعداد هجا** است:

```
یک هجا                  →  -er        big → bigger, fast → faster
دو هجا با پایان -y      →  -ier       easy → easier, happy → happier
دو هجای دیگر            →  more       careful → more careful
سه هجا و بیشتر          →  more       important → more important
```

### چند دوهجایی که هر دو را قبول می‌کنند

```
quiet, clever, simple, narrow, gentle, common, polite
→ quieter / more quiet     هر دو درست
```

اگر شک داری، `more` امن‌تر است — هیچ‌وقت غلط فاحش نیست.

### بی‌قاعده‌ها

```
good    →  better   →  the best
bad     →  worse    →  the worst
far     →  further  →  the furthest        (مجازی و مسافت)
far     →  farther  →  the farthest        (فقط مسافت)
little  →  less     →  the least
many/much → more    →  the most
```

### املا

```
big → bigger        (تک‌هجا، همخوان-مصوت-همخوان → همخوان دوبل)
large → larger      (پایان e → فقط -r)
easy → easier       (y → i)
```

### دو خطای رایج

**۱. نشانه‌گذاری مضاعف** — پرتکرارترین خطای این بخش:
```
❌ more better        ❌ more easier        ❌ most fastest
✅ better             ✅ easier             ✅ fastest
```
یک درجه، یک نشانه. (همان منطق «اگرچه… ولی…» در جزوه‌ی دوم: انگلیسی نشانه‌گذاری مضاعف را ممنوع می‌کند.)

**۲. `different than`:**
```
✅ different from      استاندارد، برای IELTS همین را بنویس
△ different to         بریتانیایی، قابل قبول
❌ different than       آمریکایی محاوره‌ای، در Writing از آن پرهیز کن
```

## ۵. تشدید و تضعیف مقایسه

اینجا بخش پرکاربرد Task 1 شروع می‌شود. صفت تفضیلی را می‌شود **درجه‌بندی** کرد:

```
much / far / significantly / considerably / substantially  →  خیلی بیشتر
somewhat / slightly / marginally / a little / a bit        →  کمی بیشتر
```

```
Sales were significantly higher in 2010 than in 2000.
The figure for France was slightly lower than that for Germany.
Unemployment rose considerably during this period.
```

⚠️ **`very` با صفت تفضیلی نمی‌آید:**
```
❌ very higher       ✅ much higher / far higher
```

`very` فقط با صفت ساده کار می‌کند: `very high` ✅

### با صفت عالی

```
by far the largest        ← تأکید قوی
easily the most popular
```
```
China was by far the largest producer.    ✅ عالی برای Task 1
```

### فهرست عملی Task 1

این‌ها را حفظ کن — در توصیف نمودار مدام لازم می‌شوند:

```
significantly higher / lower than
considerably more / less than
slightly above / below
marginally higher
roughly the same as
almost identical to
in comparison with / compared with
```

## ۶. چندبرابری و `that of`

### نسبت‌های چندبرابری

```
twice as + صفت + as              دو برابر
three times as + صفت + as        سه برابر
half as + صفت + as               نصف
```

```
The population of Iran is roughly twice as large as that of Iraq.
Car ownership was three times higher in 2010 than in 1990.
```

دو شکل هم‌ارز:
```
twice as high as X       ✅
two times higher than X  ✅ (کمی غیررسمی‌تر)
```

⚠️ `twice` با `than` نمی‌آید:
```
❌ twice higher than      ✅ twice as high as
```

### `that of` و `those of` — ابزار کلیدی Task 1

وقتی داری دو چیز را مقایسه می‌کنی، باید **چیزهای هم‌جنس** را مقایسه کنی. خطای رایج این است که یک عدد را با یک کشور مقایسه می‌کنی:

```
❌ The population of China is larger than India.
   → دارد جمعیت چین را با خودِ هند مقایسه می‌کند
✅ The population of China is larger than that of India.
   → «that» جانشین «the population» است
```

```
مفرد:  that of      The rate for men was higher than that for women.
جمع:   those of     Sales in Europe exceeded those in Asia.
```

این ساختار هم به بخش مقایسه تعلق دارد، هم به بخش جانشینی (بخش ۱۸) — و یکی از قابل‌اتکاترین نشانه‌های نوشتار آکادمیک در Task 1 است.

---

## ۷. صفت عالی

```
the + صفت-est / the most + صفت
```

**حرف اضافه‌ی بعدش:**
```
in + مکان یا گروه     the largest city in Europe
of + مجموعه           the best of the three
```

**رتبه‌های بعدی:**
```
the second largest        the third most popular
```

### تله‌ی مهم: `one of the + عالی + جمع`

```
❌ one of the most important factor
✅ one of the most important factors
```

منطقش روشن است: «یکی از مهم‌ترین**ها**» — پس اسم باید جمع باشد. ولی چون فارسی بعد از عدد و بعد از «یکی از» مفرد می‌گیرد («یکی از مهم‌ترین عوامل»)، ذهنت مفرد می‌سازد. این همان **ریشه‌ی ۳** جزوه‌ی گروه اسمی است که در لباس تازه‌ای برگشته.

```
✅ Pollution is one of the biggest problems facing cities today.
✅ This is one of the most effective solutions available.
```

### `the` را جا نینداز

```
❌ Tehran is largest city in Iran.
✅ Tehran is the largest city in Iran.
```

صفت عالی ذاتاً یکتاساز است، پس همیشه `the` می‌گیرد — همان **منبع ۳** از جزوه‌ی گروه اسمی.

## ۸. الگوهای موازی

سه ساختار کوچک با بازده‌ی خوب:

### `the more … the more …`

```
The more you practise, the better you become.
The higher the income, the greater the consumption.
```

⚠️ ترتیبش ثابت است و کاما بین دو بخش می‌آید. در Task 2 برای بیان رابطه‌ی علّی مفید است:
```
The more accessible education becomes, the more equal a society is likely to be.
```

### تکرار تفضیلی — برای بیان روند

```
It is getting harder and harder to find affordable housing.
Cities are becoming more and more crowded.
```

مفید برای Task 1 وقتی روند مستمر است.

### `as … as possible`

```
Governments should act as quickly as possible.
```

# بخش سوم — ترتیب

## ۹. فعل و مفعول را جدا نکن

قاعده‌ای ساده که یکی از قابل‌تشخیص‌ترین خطاهای فارسی‌زبان‌ها را می‌بندد:

> **بین فعل و مفعول مستقیمش چیزی نگذار.**

```
❌ I like very much this book.        ✅ I like this book very much.
❌ He speaks fluently English.        ✅ He speaks English fluently.
❌ She explained clearly the rules.   ✅ She explained the rules clearly.
❌ I understand completely your point. ✅ I completely understand your point.
```

مفعول باید **بلافاصله** بعد از فعل بیاید. قید یا می‌رود قبل از فعل، یا بعد از مفعول.

### چرا این خطا این‌قدر رایج است

چون در فارسی، فعل **آخر** جمله می‌آید و مفعول قبل از آن. یعنی الگوی ذهنی‌ات این است:

```
من  خیلی  این کتاب را  دوست دارم.
     └قید┘  └مفعول┘     └فعل┘
```

وقتی این را کلمه‌به‌کلمه به انگلیسی می‌ریزی، قید بین فعل و مفعول گیر می‌کند. راه‌حل: بعد از نوشتن، نگاه کن که آیا فعل و مفعول چسبیده‌اند.

---

## ۱۰. جای قید

سه جایگاه ممکن، و هر نوع قید جایگاه ترجیحی خودش را دارد.

```
اول جمله      Unfortunately, the project failed.
وسط جمله      She always arrives early.
آخر جمله      He spoke quietly.
```

### قیدهای تکرار → وسط

```
always, usually, often, sometimes, rarely, seldom, never, still, already
```

قاعده‌ی جایگاه وسط، سه‌خطی و دقیق است:

```
۱. بعد از فعل be                 He is always late.
۲. قبل از افعال دیگر             He always arrives late.
۳. بعد از اولین فعل کمکی         He has always been late.
                                 She will never agree.
```

```
❌ He always is late.          ✅ He is always late.
❌ I go always to the gym.     ✅ I always go to the gym.
❌ She has been always kind.   ✅ She has always been kind.
```

### قیدهای حالت → آخر (معمولاً)

```
carefully, quickly, badly, well, fluently
```
```
She explained the concept clearly.
He drives carefully.
```

### قیدهای نظر و ربط → اول، با کاما

```
Fortunately, Obviously, Clearly, Interestingly,
However, Therefore, Moreover, In addition
```
```
Clearly, this approach has serious limitations.
However, there are counterarguments.
```

توجه: `however` را در جزوه‌ی دوم دیدی — قید است، نه حرف ربط، پس نمی‌تواند دو جمله را بچسباند.

### قیدهای زمان → آخر یا اول

```
She finished the report yesterday.
Yesterday, she finished the report.
```

---

## ۱۱. ترتیب انتهای جمله

وقتی چند عبارت قیدی ته جمله جمع می‌شوند، ترتیبشان ثابت است:

> **روش ← مکان ← زمان**  (Manner → Place → Time)

```
She sang    beautifully    at the concert    last night.
            └روش┘          └مکان┘            └زمان┘
```

```
❌ She sang at the concert beautifully last night.
❌ He worked yesterday in the office quietly.
✅ He worked quietly in the office yesterday.
```

با افعال حرکتی، مکان اول می‌آید:
```
✅ They travelled to Paris by train last week.
```

### نکته‌ی عملی

در Writing به‌ندرت هر سه‌تا را همزمان داری. اگر داشتی، به‌جای چپاندنشان در یک جمله، زمان را به اول ببر:

```
سنگین:  Sales increased sharply in European markets during the 1990s.
سبک‌تر: During the 1990s, sales increased sharply in European markets.
```

---

## ۱۲. ترتیب صفت‌ها

وقتی چند صفت قبل از یک اسم می‌آیند، ترتیبشان اختیاری نیست:

```
نظر → اندازه → سن → شکل → رنگ → منشأ → جنس → کاربرد
```

```
a beautiful  large  old  round  brown  Italian  wooden  dining  table
   نظر       اندازه  سن   شکل    رنگ    منشأ     جنس     کاربرد
```

### در عمل

هیچ‌وقت هشت صفت پشت هم نمی‌گذاری. برای IELTS دو قاعده کافی است:

```
۱. صفت نظری همیشه اول:      a nice old house    ❌ an old nice house
۲. اندازه قبل از رنگ:        a big red car       ❌ a red big car
```

بیش از سه صفت پشت هم، در نوشتار آکادمیک ناجور است. اگر لازم شد، با `which` یا عبارت حرف اضافه‌ای بشکنش:

```
سنگین:  a large modern well-equipped public library
بهتر:   a large, modern public library which is well equipped
```

---

## ۱۳. مفعول غیرمستقیم

وقتی فعلی دو مفعول دارد، دو الگو ممکن است:

```
الگوی ۱:  فعل + گیرنده + شیء          He gave me the book.
الگوی ۲:  فعل + شیء + to/for + گیرنده  He gave the book to me.
```

بیشتر افعال هر دو را قبول می‌کنند: `give, send, tell, show, offer, lend, teach, buy, bring`.

### ولی چند فعل فقط الگوی ۲ را قبول می‌کنند

این فهرست کوتاه، منبع خطای رایجی است:

```
explain, describe, suggest, mention, say, announce, introduce, report
```

```
❌ He explained me the rules.        ✅ He explained the rules to me.
❌ Describe me the picture.          ✅ Describe the picture to me.
❌ She suggested me a solution.      ✅ She suggested a solution to me.
❌ He said me that…                  ✅ He said to me that… / He told me that…
```

### چرا این‌ها؟

الگویی هست ولی کامل نیست: این افعال اغلب از لاتین آمده‌اند و ساختار لاتینی‌شان را نگه داشته‌اند. برای IELTS همین فهرست کوتاه کافی است — همه‌شان افعال «انتقال اطلاعات»‌اند.

### پیوند با جزوه‌ی سوم

`suggest` را در جزوه‌ی قبل هم دیدی:
```
❌ He suggested me to apply.
✅ He suggested that I apply.
```
همان فعل، همان محدودیت، از دو زاویه.

# بخش چهارم — فاعل صوری

## ۱۴. انگلیسی فاعل اجباری دارد

یکی از پایه‌ای‌ترین تفاوت‌های دو زبان:

> **هر بند در انگلیسی باید فاعل داشته باشد. حتی وقتی فاعل معنایی وجود ندارد.**

فارسی این‌طور نیست. فارسی **فاعل را حذف می‌کند** چون شناسه‌ی فعل آن را نشان می‌دهد:

```
رفتم.           →  I went.        ❌ Went.
دیدمش.          →  I saw him.     ❌ Saw him.
باران می‌بارد.   →  It is raining. ❌ Is raining.
```

و در جاهایی که اصلاً فاعلی وجود ندارد، فارسی جمله را بدون فاعل می‌سازد و انگلیسی مجبور است یک **فاعل صوری** بگذارد:

```
دو ساعت طول می‌کشد.    →  It takes two hours.
یک مشکل هست.          →  There is a problem.
مهم است که…            →  It is important that…
```

`it` و `there` در این جمله‌ها **معنایی ندارند**. صرفاً جای خالی فاعل را پر می‌کنند، چون دستور زبان انگلیسی آن جایگاه را خالی نمی‌پذیرد.

### تشبیه برنامه‌نویسی

جایگاه فاعل مثل یک پارامتر اجباری است. اگر مقدار معناداری نداری، باید یک placeholder بفرستی. `it` و `there` همان placeholder هستند.

---

## ۱۵. `there` در برابر `it`

هر دو فاعل صوری‌اند ولی کارشان فرق می‌کند:

```
there  →  معرفی وجود چیزی. «هست»، «وجود دارد»
it     →  اشاره به چیزی مشخص، یا جانشین یک بند، یا آب‌وهوا/زمان/فاصله
```

```
There is a park near my house.      وجودش را معرفی می‌کنم
It is a very nice park.             حالا درباره‌اش می‌گویم
```

**ترتیب طبیعی همیشه همین است:** اول `there` معرفی می‌کند، بعد `it` ادامه می‌دهد.

### تله‌ی فارسی

فارسی برای هر دو از «هست/است» استفاده می‌کند:

```
یک پارک نزدیک خانه‌ی ما هست.   →  There is…
پارک قشنگی است.               →  It is…
```

نتیجه‌ی خطا:
```
❌ It is a problem in this city.        (اگر منظورت «یک مشکلی وجود دارد» بوده)
✅ There is a problem in this city.

❌ In my city there is very crowded.
✅ My city is very crowded.
```

### کاربردهای `it`

```
آب‌وهوا:   It is raining. It was cold.
زمان:      It is seven o'clock. It is Monday.
فاصله:     It is 300 kilometres from here.
مدت:       It takes two hours to get there.
جانشین بند: It is clear that the policy failed.
```

آن آخری را در جزوه‌ی دوم دیدی — فاعل صوری برای فرستادن بند سنگین به ته جمله.

### `it` + صفت + `for/of` + مصدر

الگوی بسیار پرکاربرد در Task 2:

```
It is difficult for students to find affordable housing.
It is essential for governments to act quickly.
It was kind of you to help.
```

```
for + شخص  →  وقتی صفت درباره‌ی موقعیت است     difficult, easy, important, possible
of + شخص   →  وقتی صفت درباره‌ی شخص است        kind, generous, foolish, rude
```

---

## ۱۶. ساختارهای رسمی‌تر

`there` فقط با `be` نمی‌آید. در نوشتار آکادمیک، این ترکیب‌ها لحن را بالا می‌برند:

```
There appears to be…          به‌نظر می‌رسد که…
There seems to be…
There remain several problems.
There has been a significant increase in…
There is a tendency for…
There is little evidence that…
There is no doubt that…
```

```
✅ There has been a marked decline in manufacturing employment.
✅ There appears to be a correlation between the two factors.
```

توجه کن که `There appears to be` و `There seems to be` هم‌زمان **تعدیل ادعا** هم می‌کنند — بخش hedging جزوه‌ی سوم.

و یادآوری از جزوه‌ی گروه اسمی: **`there` با اسمِ بعدش مطابقت می‌کند**، نه با خودش:
```
There is one problem.        There are several problems.
```

# بخش پنجم — جانشینی و حذف

## ۱۷. قاعده‌ی وارونه

اینجا یک تقارن جالب هست که ارزش دارد صریح دیده شود:

> **فارسی فاعل را حذف می‌کند و فعل را تکرار.**
> **انگلیسی فاعل را نگه می‌دارد و فعل را حذف.**

```
فارسی:   من می‌روم و او هم می‌رود.        ← فعل تکرار شد
انگلیسی: I'm going and so is he.          ← فعل حذف شد، فاعل ماند

فارسی:   رفتم و خریدم.                    ← فاعل دو بار حذف شد
انگلیسی: I went and bought it.            ← فاعل یک‌بار آمد و ماند
```

پس دو عادت باید همزمان عوض شوند:

**۱. فاعل را حذف نکن** (حتی وقتی معلوم است)
**۲. فعل تکراری را حذف کن** (چون تکرارش ناشیانه به‌نظر می‌رسد)

عادت دوم اختیاری است — نبودش خطا نیست، فقط متن را سنگین می‌کند. عادت اول اجباری است.

```
❌ Is very important to study hard.       ✅ It is very important…
❌ When arrived home, was tired.          ✅ When I arrived home, I was tired.
```

### استثنای واقعی: هم‌پایگی با فاعل یکسان

وقتی دو بند با `and/but/or` وصل می‌شوند و فاعلشان یکی است، فاعل دوم حذف می‌شود:

```
✅ He opened the door and walked in.
✅ She studied hard but failed the exam.
```

این تنها جایی است که انگلیسی فاعل را می‌اندازد.

---

## ۱۸. جانشین‌ها

### `one` و `ones` — جانشین اسم شمارا

```
Which shirt do you want? — The blue one.
I need a pen. Do you have one?
These shoes are old; I need new ones.
```

⚠️ بدون `one` نمی‌شود:
```
❌ Which one? — The blue.
✅ Which one? — The blue one.
```

فارسی می‌گوید «آبیه» و صفت به‌تنهایی می‌ایستد. انگلیسی نمی‌گذارد — مگر با `the` + صفت در معنای گروه انسانی (جزوه‌ی اول، بخش ۱۴).

`one` برای ناشمارا کار نمی‌کند:
```
❌ I need water. Do you have one?
✅ I need water. Do you have any?
```

### `so` و `not` — جانشین یک بند کامل

```
"Is he coming?" — "I think so."       ← so = that he is coming
"Will it rain?" — "I hope not."       ← not = that it won't rain
```

```
I think so.  ·  I hope so.  ·  I'm afraid so.
I don't think so.  ·  I hope not.  ·  I'm afraid not.
```

⚠️ `think` منفی را روی خودش می‌گیرد، نه روی `so`:
```
✅ I don't think so.        ❌ I think not. (کهنه و ادبی)
```

### `do so` / `do it` / `do that` — جانشین گروه فعلی

```
He was asked to revise the report, and he did so immediately.
```

`do so` رسمی است و در Writing خوب می‌نشیند. `do it` خنثی‌تر است.

### `that of` / `those of` — در مقایسه

بخش ۶ را ببین. مهم‌ترین جانشین برای Task 1.

---

## ۱۹. حذف با فعل کمکی

قاعده‌ی مولد این بخش:

> **فعل کمکی را نگه دار، بقیه‌اش را بینداز.**

اگر فعل کمکی نیست، `do/does/did` بیاور.

### موافقت مثبت

```
so + فعل کمکی + فاعل
```
```
She can swim, and so can I.
He works hard, and so does she.
I have finished, and so have they.
```

### موافقت منفی

```
neither / nor + فعل کمکی + فاعل
```
```
I don't smoke, and neither does he.
She hasn't arrived, and nor have the others.
```

⚠️ توجه: بعد از `neither` فعل **مثبت** می‌آید. منفی بودن را خودِ `neither` حمل می‌کند:
```
❌ Neither doesn't he.        ✅ Neither does he.
```

### مخالفت

```
فاعل + فعل کمکی (بدون so/neither)
```
```
I like coffee, but he doesn't.
She hasn't finished, but I have.
```

### جواب کوتاه

```
"Are you coming?" — "Yes, I am." / "No, I'm not."
"Did she call?" — "Yes, she did."
"Have you seen it?" — "No, I haven't."
```

⚠️ جواب کوتاه **باید** فعل کمکی داشته باشد:
```
❌ Yes, I.        ❌ Yes, I coming.        ✅ Yes, I am.
```

### `too` و `either`

```
too      →  در جمله‌ی مثبت      I like it too.
either   →  در جمله‌ی منفی      I don't like it either.
```

```
❌ I don't like it too.        ✅ I don't like it either.
```

فارسی «هم» را در هر دو حالت به کار می‌برد («من هم دوست دارم» / «من هم دوست ندارم») و همین باعث خطا می‌شود.

# بخش ششم — سؤال

## ۲۰. وارونگی و `do`

فارسی سؤال را با **آهنگ صدا** یا با «آیا» می‌سازد. ترتیب کلمات عوض نمی‌شود:

```
تو آماده‌ای.        →  تو آماده‌ای؟          ← همان ترتیب
او دیر آمد.        →  چرا او دیر آمد؟      ← همان ترتیب
```

انگلیسی **ترتیب را عوض می‌کند**:

```
You are ready.      →  Are you ready?
He came late.       →  Why did he come late?
```

### دو قاعده

**۱. فعل کمکی جلوی فاعل می‌رود:**
```
She is working.     →  Is she working?
They have finished. →  Have they finished?
He can swim.        →  Can he swim?
```

**۲. اگر فعل کمکی نیست، `do/does/did` بیاور:**
```
You like it.        →  Do you like it?
She works here.     →  Does she work here?
They arrived.       →  Did they arrive?
```

⚠️ بعد از `do/does/did`، فعل اصلی **به شکل ساده** برمی‌گردد:
```
❌ Does she works here?      ✅ Does she work here?
❌ Did they arrived?         ✅ Did they arrive?
```

### سؤال از فاعل — استثنای ظاهری

وقتی کلمه‌ی پرسشی خودش فاعل است، **هیچ تغییری لازم نیست**:

```
Who called?          ❌ Who did call?
What happened?       ❌ What did happen?
Which team won?
```

منطقش ساده است: جابه‌جایی‌ای وجود ندارد که انجام شود، چون کلمه‌ی پرسشی از اول سر جای فاعل است.

### پیوند با جزوه‌ی دوم

در جزوه‌ی قبل دیدی که وقتی سؤال **داخل** جمله‌ی دیگری می‌رود، این وارونگی **برداشته می‌شود**:

```
Where is she?           →  I don't know where she is.
```

پس دو عملیات متضاد داری که باید از هم جدا بمانند. اگر یکی‌شان زیادی خودکار شود، در قلمرو آن یکی هم شلیک می‌کند — که همان توضیحی بود که در بخش سؤال درون‌نشانده دادم.

---

## ۲۱. tag question

سؤال کوتاهی که ته جمله می‌آید. قاعده‌اش کاملاً مکانیکی است:

> **جمله مثبت → تگ منفی. جمله منفی → تگ مثبت.**
> **فعل کمکی جمله + ضمیر فاعل.**

```
It's cold, isn't it?
You don't smoke, do you?
She has finished, hasn't she?
They will come, won't they?
He can't swim, can he?
```

اگر فعل کمکی نیست، `do/does/did`:
```
You like coffee, don't you?
She called yesterday, didn't she?
```

### چند مورد خاص

```
I am late, aren't I?           ← «amn't» وجود ندارد
Let's go, shall we?
Close the door, will you?
Nobody came, did they?         ← nobody معنای منفی دارد
There's a problem, isn't there?
```

### آهنگ صدا

```
آهنگ نزولی  →  دنبال تأیید هستم، جواب را می‌دانم
آهنگ صعودی  →  واقعاً نمی‌دانم، دارم می‌پرسم
```

### در IELTS

tag question **اجباری نیست** و در Writing جایی ندارد. در Speaking اگر طبیعی آمد، خوب است؛ زورکی جا دادنش لازم نیست. ارزشش بیشتر در **فهمیدن** است تا تولید.

---

## ۲۲. تله‌ی جواب به سؤال منفی

این یکی ریشه‌ی مستقیم فارسی دارد و در Speaking واقعاً پیش می‌آید.

فارسی برای جواب مثبت به سؤال منفی، کلمه‌ی مخصوصی دارد: **«چرا»**.

```
نمی‌آیی؟   —  چرا، می‌آیم.        ← جواب مثبت به سؤال منفی
نمی‌آیی؟   —  نه، نمی‌آیم.
```

**انگلیسی معادل «چرا» را ندارد.** فقط `yes` و `no` دارد، و ملاکشان **خودِ واقعیت** است، نه شکل سؤال:

```
Don't you like it?
   — Yes, I do.      دوست دارم
   — No, I don't.    دوست ندارم
```

قاعده: **اگر جوابت مثبت است، `yes` بگو — فارغ از اینکه سؤال منفی بوده یا مثبت.**

```
Aren't you coming?
   ✅ Yes, I am.      (می‌آیم)
   ✅ No, I'm not.    (نمی‌آیم)
```

خطای رایج این است که چون سؤال منفی بوده، فارسی‌زبان `no` می‌گوید ولی منظورش «چرا، می‌آیم» است — و شنونده دقیقاً برعکس می‌فهمد.

**راه امن:** به `yes/no` تنها اکتفا نکن. جمله‌ی کوتاه را هم بگو (`Yes, I am` / `No, I'm not`). این ابهام را کامل از بین می‌برد.

# بخش هفتم — واژه‌سازی

## ۲۳. یک ریشه، چهار جایگاه

این بخش رسماً به Lexical Resource مربوط است، ولی خطایش **دستوری** است: کلمه‌ی درست را در جایگاه اشتباه می‌گذاری.

> **هر ریشه معمولاً چهار شکل دارد. جایگاه در جمله تعیین می‌کند کدام را می‌خواهی.**

```
فعل        اسم           صفت            قید
analyse    analysis      analytical     analytically
succeed    success       successful     successfully
benefit    benefit       beneficial     beneficially
economise  economy       economic       economically
create     creation      creative       creatively
depend     dependence    dependent      —
differ     difference    different      differently
compete    competition   competitive    competitively
achieve    achievement   achievable     —
persuade   persuasion    persuasive     persuasively
```

### خطای معمول: اسم در جایگاه صفت

```
❌ This is a benefit policy.          ✅ a beneficial policy
❌ He is very success.                 ✅ very successful
❌ The economy situation is bad.       ✅ The economic situation
❌ the different between them          ✅ the difference between them
```

### روش تشخیص

قبل از نوشتن کلمه، بپرس **چه چیزی در این جایگاه می‌نشیند**:

```
بعد از a/the و قبل از اسم     →  صفت
بعد از be                     →  صفت
جای فاعل یا مفعول             →  اسم
بعد از حرف اضافه              →  اسم (یا gerund — جزوه‌ی سوم)
توصیف فعل                     →  قید
```

---

## ۲۴. نشانه‌های پسوندی

پسوندها به تو می‌گویند کلمه در کدام مقوله است. این فهرست حدس زدن را قابل‌اتکا می‌کند:

```
اسم:   -tion, -sion, -ment, -ness, -ity, -ance, -ence,
       -ship, -ism, -ist, -er, -or, -age, -hood

صفت:   -ful, -less, -able, -ible, -ive, -ous, -al,
       -ic, -ent, -ant, -ary, -ish

فعل:   -ise / -ize, -ify, -en, -ate

قید:   -ly
```

### پیشوندهای منفی و تغییردهنده

```
un-    unnecessary, unemployment
in-    inefficient, inequality
im-    impossible, impatient       (قبل از m/p)
il-    illegal, illiterate         (قبل از l)
ir-    irrelevant, irresponsible   (قبل از r)
dis-   disagree, disadvantage
mis-   misunderstand, misuse
non-   non-existent, non-renewable
over-  overestimate, overpopulation
under- underestimate, underdeveloped
re-    reconsider, renewable
```

توجه به `im-/il-/ir-` — انتخابشان بر اساس **حرف اول کلمه** است، نه دلبخواه.

### واژگان پرکاربرد IELTS با این پیشوندها

```
unemployment, inequality, overpopulation, underdeveloped,
non-renewable, disadvantage, misunderstanding, overestimate
```

---

## ۲۵. صفت در برابر قید

اینجا یک ریشه‌ی واقعی فارسی هست.

**در فارسی، صفت و قید اغلب یک شکل‌اند:**

```
او سریع است.       صفت
او سریع می‌دود.     قید — همان کلمه
```

انگلیسی این دو را جدا می‌کند:

```
He is quick.       صفت
He runs quickly.   قید
```

```
❌ He speaks English good.        ✅ He speaks English well.
❌ She drives very careful.       ✅ She drives very carefully.
❌ They worked hardly.            ✅ They worked hard.  (معنا عوض شد!)
```

### `good` و `well`

```
good  →  صفت      This is a good essay.
well  →  قید      She writes well.
```

استثنا: `well` وقتی درباره‌ی سلامتی است، صفت است:
```
I don't feel well today.    ✅
```

### قیدهایی که `-ly` نمی‌گیرند

```
fast, hard, late, early, high, low, straight
```
```
He works hard.       ✅  (نه hardly)
She arrived late.    ✅  (نه lately)
```

⚠️ **چند تا از این‌ها با `-ly` معنای کاملاً متفاوت پیدا می‌کنند:**

```
hard    سخت / زیاد        hardly    به‌سختی، تقریباً هیچ
late    دیر               lately    اخیراً
near    نزدیک             nearly    تقریباً
high    بالا              highly    بسیار (رسمی)
```

```
He works hard.        زیاد کار می‌کند
He hardly works.      تقریباً کار نمی‌کند     ← معنای وارونه
```

این جفت‌ها خطای پرهزینه‌ای می‌سازند چون معنا را وارونه می‌کنند، نه اینکه فقط ناجور کنند.

## ۲۶. جفت‌های اشتباه‌انداز

صفت‌هایی که از یک ریشه‌اند ولی معنایشان فرق می‌کند. در IELTS پرتکرارند:

| جفت | تفاوت |
|---|---|
| economic / economical | مربوط به اقتصاد / صرفه‌جو |
| historic / historical | تاریخ‌ساز، مهم / مربوط به تاریخ |
| effective / efficient | مؤثر (نتیجه می‌دهد) / کارآمد (بدون اتلاف) |
| sensible / sensitive | عاقلانه / حساس |
| considerable / considerate | قابل‌توجه / ملاحظه‌کار |
| industrial / industrious | صنعتی / پرکار |
| literal / literary | تحت‌اللفظی / ادبی |
| classic / classical | نمونه‌وار، درجه‌یک / کلاسیک (موسیقی، دوره) |

```
✅ economic growth              رشد اقتصادی
✅ an economical car            ماشین کم‌مصرف

✅ an effective policy          سیاستی که جواب می‌دهد
✅ an efficient system          سیستمی که منابع را هدر نمی‌دهد
```

`economic` و `effective` آن‌هایی هستند که در Task 2 واقعاً لازم می‌شوند. بقیه را بشناس، ولی لازم نیست تولیدشان کنی.

### صفت‌های `-ed` و `-ing`

خطای بسیار رایج و ساده برای رفع:

```
-ed   →  احساسِ خودِ شخص       I am bored.
-ing  →  ویژگیِ چیزی که باعث می‌شود   The lecture is boring.
```

```
❌ I am boring.        (یعنی: من آدم کسل‌کننده‌ای هستم)
✅ I am bored.         (یعنی: حوصله‌ام سر رفته)

❌ I am very interesting in history.
✅ I am very interested in history.
```

جفت‌های پرکاربرد:
```
interested / interesting      confused / confusing
surprised / surprising        tired / tiring
worried / worrying            frustrated / frustrating
```

# بخش هشتم — جمع‌بندی

## ۲۷. شش ریشه‌ی خطای فارسی‌زبان‌ها

**ریشه ۱ — فارسی ترتیب آزاد دارد، انگلیسی ندارد.**
«را» نقش مفعول را علامت می‌زند، پس فارسی می‌تواند جابه‌جا کند. انگلیسی نشانه‌ای ندارد و نقش را از جایگاه می‌فهمد. نتیجه: قید بین فعل و مفعول گیر می‌کند.
```
❌ I like very much this film.
```

**ریشه ۲ — فارسی فاعل را حذف می‌کند، انگلیسی نمی‌تواند.**
«رفتم» یک جمله‌ی کامل است. `Went` نیست. و در جاهایی که فاعل معنایی وجود ندارد، انگلیسی مجبور است `it` یا `there` بگذارد.
```
❌ Is very important to…        ✅ It is very important to…
```

**ریشه ۳ — «هست» هم `there is` است هم `it is`.**
فارسی این دو را جدا نمی‌کند. نتیجه: `It is a problem in this city` وقتی منظور `There is a problem` بوده.

**ریشه ۴ — صفت و قید در فارسی اغلب یک شکل‌اند.**
«سریع» هم صفت است هم قید. انگلیسی `-ly` می‌خواهد.
```
❌ He speaks English good.      ✅ …well.
```

**ریشه ۵ — «هم» در فارسی هم مثبت است هم منفی.**
«من هم دوست دارم» / «من هم دوست ندارم». انگلیسی `too` و `either` را جدا کرده.

**ریشه ۶ — «چرا» معادل انگلیسی ندارد.**
جواب مثبت به سؤال منفی در فارسی کلمه‌ی مخصوص دارد؛ در انگلیسی باید `Yes` بگویی، که برای گوش فارسی غلط حس می‌شود.

## ۲۸. این جزوه در IELTS

### Writing Task 1 — بیشترین بازده اینجاست

بیش از نیمی از زبانِ Task 1 از این جزوه می‌آید:

```
significantly higher / considerably lower than
twice as high as / three times as many as
by far the largest
the second highest figure
that of / those of
compared with / in comparison with
It can be seen that…

```

الگوی جمله‌ای که مدام لازم می‌شود:
```
The figure for X was significantly higher than that for Y.
X accounted for by far the largest share, at 45 percent.
```

⚠️ خطای پرتکرار Task 1 که این جزوه می‌بندد:
```
❌ The population of China is larger than India.
✅ …larger than that of India.
```

### Writing Task 2

```
It is difficult for governments to…
There is little evidence that…
The more accessible education becomes, the more…
one of the most significant factors        ← جمع!
economic / effective / beneficial          ← شکل درست کلمه
```

و از بخش واژه‌سازی: مطمئن شو کلمه در جایگاه درست است. `benefit` اسم است، `beneficial` صفت — این خطا مستقیماً به Lexical Resource ضربه می‌زند.

### Speaking

```
so do I / neither do I     →  Part 1، طبیعی و روان
too / either               →  خطای پرشنیدنی
جواب به سؤال منفی          →  Part 1 و 3
good / well                →  Part 1، مکرر
tag question               →  اختیاری، زورکی جا نده
```

نکته: بخش جانشینی و حذف (بخش ۱۹) در Speaking بیشترین تأثیر را دارد، چون تکرارِ کامل جمله، گفتار را کند و ناشیانه می‌کند:

```
△ I like coffee and my brother likes coffee too.
✅ I like coffee and so does my brother.
```

## ۲۹. فهرست خطاهای رایج

```
۱.  [ ] بین فعل و مفعول چیزی نگذاشته‌ام؟
۲.  [ ] قید تکرار جای درستی است؟ (after be, before other verbs)
۳.  [ ] more better / most fastest ننوشته‌ام؟
۴.  [ ] than را جا نینداخته‌ام؟ (نه from، نه that)
۵.  [ ] در مقایسه، that of / those of گذاشته‌ام؟
۶.  [ ] one of the + عالی + اسم جمع؟

۱۲. [ ] good/well و صفت/قید درست است؟

## ۳۰. جدول مرجع نهایی

### مقایسه

```

دو هجا با -y → -ier     دو هجای دیگر → more

much / far / significantly / considerably  +  تفضیلی

## ۳۱. تمرین با جواب

### الف — خطای ترتیب را اصلاح کن

1. I like very much this city.
2. She speaks fluently three languages.
3. He always is late for meetings.
4. They worked in the office yesterday quietly.
5. I go usually to the gym after work.

<details>
<summary>جواب‌ها</summary>

1. I like this city **very much.** (فعل و مفعول را جدا نکن)
2. She speaks **three languages fluently.**
3. He **is always** late. (بعد از be)
4. They worked **quietly in the office yesterday.** (روش ← مکان ← زمان)
5. I **usually go** to the gym after work. (قبل از فعل اصلی)

</details>

### ب — مقایسه را کامل کن

6. Tehran is much ___ (crowded) than Shiraz.
7. This is by far ___ (good) solution available.
8. The population of Iran is roughly twice ___ large ___ that of Iraq.
9. Unemployment is one of the most serious ___ (problem) facing the country.
10. The figure for men was slightly higher than ___ for women.

<details>
<summary>جواب‌ها</summary>

6. **more crowded**
7. **the best** (عالی → the)
8. twice **as** large **as**
9. **problems** (one of the + عالی + جمع)
10. **that** (that = the figure)

</details>

### ج — خطاها را پیدا کن

11. Is very difficult to find a job nowadays.
12. In my country there is very hot in summer.
13. He explained me the whole situation.
14. She is more better at maths than her brother.
15. I don't like horror films too.
16. He speaks English very good.
17. The economy situation has worsened.
18. I am very interesting in this topic.
19. This is one of the biggest problem in our city.
20. The population of China is larger than India.

<details>
<summary>جواب‌ها</summary>

11. **It is** very difficult… (فاعل صوری — ریشه ۲)
12. In my country **it is** very hot… (there/it — ریشه ۳)
13. He explained **the whole situation to me.**
14. She is **better** at maths. (نشانه‌گذاری مضاعف)
15. I don't like horror films **either.** (منفی → either)
16. He speaks English very **well.** (قید — ریشه ۴)
17. The **economic** situation. (صفت لازم است)
18. I am very **interested** in this topic.
19. one of the biggest **problems.**
20. …larger than **that of** India.

</details>

22. She can't drive and I can't drive.
23. He has finished but I have not finished.

<details>
<summary>جواب‌ها</summary>

### ه — جواب بده

24. "Aren't you coming with us?" — منظورت این است که می‌آیی. چه می‌گویی؟
25. "Don't you agree?" — منظورت این است که موافق نیستی. چه می‌گویی؟

<details>
<summary>جواب‌ها</summary>

24. **"Yes, I am."** — نه `No`. انگلیسی معادل «چرا» ندارد؛ ملاک واقعیت است، نه شکل سؤال.
25. **"No, I don't."**

نکته: همیشه جمله‌ی کوتاه را هم بگو. `Yes` یا `No` تنها، در سؤال منفی ابهام می‌سازد.

</details>

### و — ترجمه‌ی جمله‌ی تله‌دار فارسی

جمله‌ی فارسی: **«در شهر ما آلودگی خیلی بیشتر از قبل است و این یکی از بزرگ‌ترین مشکلات ماست.»**

ترجمه کن و تله‌ها را بشمار.

<details>
<summary>جواب</summary>

```
✅ In our city, pollution is much worse than it used to be, and
   this is one of our biggest problems.

✅ (روان‌تر) Pollution in our city is far more severe than before,
   and it is one of the most serious problems we face.
```

**پنج تله:**

**۱. «در شهر ما … است» → فاعل لازم است.** ذهن فارسی ممکن است `In our city is very polluted` بسازد. باید فاعل داشته باشد: `pollution is…` یا `our city is…`.

**۲. «خیلی بیشتر» → `much worse` / `far more`، نه `very more`.** `very` با تفضیلی نمی‌آید.

**۳. «بیشتر از قبل» → `than before` یا `than it used to be`، نه `than past`.** و `than` نه `from`.

**۴. «یکی از بزرگ‌ترین مشکلات» → اسم جمع.** فارسی هم اینجا جمع دارد («مشکلات»)، پس این یکی راحت‌تر است — ولی اگر جمله «یکی از بزرگ‌ترین مشکل» بود، تله فعال می‌شد.

**۵. «مشکلات ما» → `our problems`، نه `the our problems`.** یک جایگاه، یک determiner — جزوه‌ی اول، بخش ۱۵.

**نکته:** باز هم یک جمله‌ی ساده‌ی فارسی، تصمیم‌هایی از هر چهار جزوه می‌خواهد.

</details>

## ۳۲. نقشه‌ی کل مجموعه

با این، هر هفت حوزه‌ی گرامری که در ابتدا فهرست شد پوشش داده شده است. نقشه‌ی نهایی:

```
جزوه‌ی زمان‌ها          →  verb = {tense, aspect}
جزوه‌ی مجهول و شرطی     →  + voice، و نردبان فاصله
جزوه‌ی گروه اسمی        →  determiner = f(countability, identifiability)
جزوه‌ی جمله‌ی پیچیده     →  سه جایگاه: اسم، صفت، قید
جزوه‌ی الگوهای فعل      →  + modality، و محور «رو به جلو / واقع‌شده»
این جزوه               →  چیدن، مقایسه، صرفه‌جویی
```

سه ایده در کل مجموعه بارها برگشتند و ارزش دارد کنار هم دیده شوند:

**۱. گذشته = فاصله.** در شرطی‌ها فاصله از واقعیت، در نقل قول فاصله از لحظه‌ی گفتن، در `Could you…?` فاصله‌ی ادب. یک مکانیزم، سه کاربرد.

**۲. نشانه‌گذاری مضاعف ممنوع است.** `more better`، `اگرچه… ولی…`، `the man who I saw him`، `discuss about` — همه یک خانواده‌اند: فارسی دو نشانه می‌گذارد، انگلیسی یکی می‌خواهد.

**۳. سخت‌ترین خطاها آن‌هایی هستند که در فارسی درست‌اند.** «قیمت‌ها بالا رفته است»، «مردی که او را دیدم»، «اگرچه… ولی…»، «بحث کردن درباره‌ی». گوش درونی‌ات تأییدشان می‌کند، پس موقع بازخوانی از کنارشان رد می‌شوی. این دسته به بررسی آگاهانه نیاز دارد، نه به حس زبانی.

اگر روزی خواستی کل مجموعه را در یک صفحه مرور کنی، بخش «ریشه‌های خطا» هر جزوه را کنار هم بگذار. آن شش‌تا در چهار جزوه، عملاً نقشه‌ی کاملِ نقاط اصطکاک فارسی و انگلیسی است.
